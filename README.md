# Zecpath Job Portal Backend

##  Project Overview
This is a Django REST API project for a job portal system.

##  Features
- User Management (Candidate / Recruiter)
- Job Posting
- Job Application System
- Resume Upload
- Admin Panel

## 🛠 Tech Stack
- Python
- Django
- Django REST Framework
- SQLite

##  Project Structure
- User → Employer / Candidate
- Employer → Jobs
- Candidate → Applications

##  Run Project
1. Create virtual environment
2. Install dependencies
3. Run server:
   python manage.py runserver
